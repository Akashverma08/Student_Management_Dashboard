# Student Management Dashboard

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/Akashverma08/Student_Management_Dashboard.git
```

### 2. Navigate to the project directory

```bash
cd Student_Management_Dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Assumptions

* Node.js and npm are installed.
* The project is intended to run locally.
* All required dependencies are installed using `npm install`.
* The application runs using the Next.js development server.
